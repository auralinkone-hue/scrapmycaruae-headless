## Duplicate and preservation safeguards

- Only exact allowlisted slugs can render a note; unknown, prototype and all other protected slugs return no mapping.
- If the already-rendered Wix body contains a link to the mapped destination, the template note is omitted. The check recognizes relative/absolute same-site URLs, query/fragment and trailing-slash variants. Home, Free Quote, unrelated routes, external lookalikes and non-link attributes do not suppress the relevant note.
- Existing shared header/footer links are not article-body links and do not suppress this contextual note. Batch 1 found the proposed primary link absent in all seven bodies.
- `articleHtml`, Ricos rendering, Wix reads/fieldsets, title/description/canonical resolution, structured-data construction, publication/update dates, cover images, author/related/latest loading, sidebar catalogue/form, redirects, caching and quote handoff are unchanged.
- The new mapping/duplicate check is synchronous and imports no SDK, request or cache helper. No additional Wix API request, browser fetch, retry, full-inventory read or dependency.
- The aside uses natural wrapping, a 44px minimum link target, visible keyboard focus, a decorative SVG arrow and reduced-motion CSS. The rest of the article layout is unchanged.
